# Лабораторна робота №1
## Шифри заміни та перестановки

### Мета роботи

Ознайомитися з принципами роботи класичних шифрів заміни та перестановки, реалізувати алгоритми шифрування і розшифрування, перевірити їх правильність за допомогою автоматизованого тестування.

### Технології

- JavaScript (Node.js)
- Node.js 22
- Vitest 5.1.0
- npm
- UTF-8

### Реалізовані алгоритми

1. **Моноалфавітна заміна**
   - Генерація алфавіту заміни на основі ключового слова.
   - Шифрування та розшифрування.

2. **Шифр Віженера**
   - Шифрування з використанням ключового слова.
   - Розшифрування.
   - Збереження пробілів та розділових знаків.

3. **Блочна перестановка**
   - Перестановка символів у блоках відповідно до ключа.
   - Неповний останній блок залишається без змін.
   - Режими `preserve` та `lettersOnly`.

4. **Вертикальна перестановка**
   - Запис тексту в таблицю по рядках.
   - Читання стовпців у порядку ключа.
   - Доповнення останнього рядка службовими символами.
   - Видалення доповнення під час розшифрування.

### Встановлення

Необхідно мати встановлений Node.js.

Клонування репозиторію та встановлення залежностей:

```bash
git clone <посилання-на-репозиторій>
cd lab1-ciphers
npm install
```

### Запуск програми

```bash
npm start
```

Програма відкриває консольне меню, у якому можна вибрати алгоритм, операцію, ввести текст вручну або прочитати його з файлу.

Результат можна зберегти у текстовий файл.

### Автоматизоване тестування

Запуск усіх тестів:

```bash
npm test
```

Запуск окремого тестового файлу:

```bash
npm test -- tests/vigenere.test.js
```

Під час виконання лабораторної роботи було реалізовано чотири класичні алгоритми шифрування та розшифрування. Розроблено консольний інтерфейс, реалізовано роботу з текстовими файлами UTF-8 та перевірку коректності ключів.
